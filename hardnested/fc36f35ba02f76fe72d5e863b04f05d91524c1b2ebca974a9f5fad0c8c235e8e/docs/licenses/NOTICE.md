## Hardnested / crypto1_bs — GPL-3.0-or-later, GPL-2.0-or-later and MIT

The native Rust solver adapts these sources from the reviewed Proxmark3
revision below:

- `properties.rs`, `reduction.rs`, `solver.rs` and table loading in `tables.rs`:
  [client/src/cmdhfmfhard.c](https://github.com/RfidResearchGroup/proxmark3/blob/2bf48a02c8f45af06e9811f18f37348facf25292/client/src/cmdhfmfhard.c).
- `candidates.rs`: candidate generation from that driver and nonce preparation
  from [hardnested_bruteforce.c](https://github.com/RfidResearchGroup/proxmark3/blob/2bf48a02c8f45af06e9811f18f37348facf25292/client/deps/hardnested/hardnested_bruteforce.c).
- `bitslice.rs`: [hardnested_bf_core.c](https://github.com/RfidResearchGroup/proxmark3/blob/2bf48a02c8f45af06e9811f18f37348facf25292/client/deps/hardnested/hardnested_bf_core.c)
  and `hardnested_bruteforce.c`, based on
  [crypto1_bs](https://github.com/aczid/crypto1_bs).
- Embedded table assets: generated by
  [hardnested_tables.c](https://github.com/RfidResearchGroup/proxmark3/blob/2bf48a02c8f45af06e9811f18f37348facf25292/client/deps/hardnested/hardnested_tables.c);
  the pack retains the upstream LZ4 frames byte-for-byte.

The Rust adaptation is distributed under GPL-3.0-or-later. The original
